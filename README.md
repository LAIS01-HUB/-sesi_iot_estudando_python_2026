
# Estudando Python

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias

- Python
- VS Code

## Exercícios

1. Soma de dois números inteiros
2. Apresentação dos números de 1 a 100
3. Média de três números
4. Conversor de temperatura de Celsius para Fahrenheit
5. Identificação de número par ou ímpar
6. Cálculo de fatorial
7. Verificador de ano bissexto
8. Verificação de número positivo, negativo ou zero
9. Comparação de dois números
10. Verificação de idade
11. Classificação de triângulos

## Para testar

Abra o terminal do VS Code e execute o arquivo desejado utilizando o comando:

```bash
python nome_arquivo.py
```

Exemplo:

```bash
python soma.py
```
